Open source

        
Free. Open source. Private.

        
The code is public and everything runs on your Mac.

        
Read the code on GitHub

      

      
    
        
  • License
    MIT. Free to use, read and change.
    • 
        
  • Mapping
    No AI involved. It only reads the folders you choose and never changes a file.
    • 
        
  • Secrets
    Never opened. Password files, keys and credentials appear on the map by name only.
    • 
        
  • Your data
    Stays on your Mac. The map, settings and boards live in one folder you can open.
