# Visual Brain 0.2.41

- Nuova scheda **Dev** al posto di Git, nell'Operativa. In «Codice» si legge il repository come in un editor: l'elenco dei file che Git conosce, colorati se modificati, nuovi o eliminati; i file aperti in schede, con numeri di riga ed evidenziazione della sintassi; la ricerca di un file per nome (⌘P) e del testo in tutto il repository (⌘⇧F); le modifiche di un file rispetto all'ultimo commit; «Apri nell'editor» (VS Code o Cursor, alla riga che stai leggendo) e «Mappa». «Cronologia» è la vista Git di prima. Dal selettore in alto ci si collega a qualsiasi repository indicizzato, non solo a quello del nodo selezionato. La scheda è in sola lettura e i file di credenziali e chiavi si aprono solo su richiesta.
- Corretto: dopo un aggiornamento o una riapertura dell'app, le sessioni di Claude Code a schermo intero tornavano nello schermo normale, con righe sfasate e fotogrammi finiti nella cronologia. Ora il terminale riprende lo schermo intero e Claude ridisegna tutto una volta.
- Meno memoria: le passate complete dell'indicizzazione usano circa 1 GB in meno e la ricarica della mappa circa 800 MB in meno, con archi e pesi identici. Le fasi globali sono anche più veloci.
