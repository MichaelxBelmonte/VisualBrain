# Visual Brain 0.2.60

- **Account aggiuntivi più facili da trovare.** In Impostazioni → Agenti c'è ora la sezione «Account aggiuntivi», sempre visibile sotto l'elenco delle CLI. Scegli Claude Code o Codex, scrivi un nome e premi «Aggiungi account»: si apre il terminale per l'accesso. Gli account già aggiunti sono elencati nella stessa sezione, con accesso, Avanzate e Rimuovi.
