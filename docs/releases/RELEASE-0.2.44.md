# Visual Brain 0.2.44

- La ricerca ⌘K permette di filtrare cartelle, progetti, file, codice, documenti, immagini/media e oggetti/collegamenti. I filtri vengono applicati prima del limite dei risultati.
- Dev mostra il codice e permette di cercare nei file anche nelle cartelle senza Git. Dal pannello GitHub puoi collegare l’account, scegliere un repository e sincronizzarlo. Il primo collegamento conserva i file locali; gli aggiornamenti successivi si fermano in presenza di modifiche locali o cronologie divergenti. La pubblicazione dei commit locali è una scelta esplicita. Richiede GitHub CLI.
- Le configurazioni delle squadre vengono salvate nel profilo dell’app: agenti, ruoli, modelli, effort, nomi e impostazioni. In Avvia → Squadre salvate puoi ricaricarle dopo un riavvio e creare nuove sessioni. Il salvataggio vale per gli avvii con questa versione; non ricostruisce conversazioni o sessioni già perse.
