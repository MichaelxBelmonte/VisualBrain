# Visual Brain 0.2.51

- **Menu rapido dei terminali.** In Operativa, apri il menu accanto alla ricerca nella barra laterale oppure premi **Ctrl+Maiusc+Spazio**. Usa le frecce per leggere le ultime righe di ciascuna sessione. Premi **Invio** per aprire il terminale selezionato o **Esc** per tornare al punto di partenza.
- **Scelta del modello.** La voce **Modello all’avvio** indica il modello con cui è partita la sessione. Nei terminali agente compatibili, **Copia /model e apri** apre il terminale e copia il comando negli appunti, pronto da incollare. Per avviare un’altra sessione sullo stesso nodo, scegli **Nuova sessione con un altro modello**.
