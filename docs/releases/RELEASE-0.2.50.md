# Visual Brain 0.2.50

- **Avvio squadra.** Scrivi l’obiettivo e scegli agente, modello ed effort per tutta la squadra. Con **Personalizza per agente** puoi cambiare le scelte dei singoli membri. In **Altre opzioni** trovi la squadra di destinazione e le configurazioni salvate. Una proposta con il solo orchestratore parte con zero operatori.
- **Bacheca Lavoro.** Ogni incarico indica a chi è assegnato e se è in attesa, in corso, bloccato o completato. La sezione **Serve te** raccoglie le decisioni in sospeso. Quando è vuota, un riepilogo indica come procede la squadra.
- **Mappa all’apertura.** Alla prima scansione compaiono i nodi mentre l’indice calcola i collegamenti. Alle aperture successive, se la vista iniziale corrisponde a quella salvata, Visual Brain la mostra durante il caricamento e la aggiorna anche con le modifiche ai file avvenute ad app chiusa.
- **Riapertura dei terminali.** Quando ti ricolleghi a un programma a schermo intero, Visual Brain gli dà il tempo di ridisegnare il contenuto prima di ripristinare le dimensioni del terminale.
- **Controllo dei pacchetti locali.** Prima della pubblicazione, lo script di release verifica che il pacchetto provenga da una copia Git pulita e che il relativo commit sia presente sul remoto con una build riuscita.
